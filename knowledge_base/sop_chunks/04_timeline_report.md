# Timeline and Reporting

Dokumen menyebut petugas menerima, mencatat, memverifikasi, mencari informasi lanjutan, dan laporan hasil operasi disampaikan melalui mekanisme resmi.

SARFlow timeline should log:

- laporan awal diterima;
- identitas/kontak pelapor dicatat;
- lokasi awal atau titik terakhir diperoleh;
- data korban diperbarui;
- permintaan verifikasi dikirim;
- update koordinat/link maps diterima;
- perubahan cuaca/lapangan dicatat;
- konflik data ditemukan;
- draft laporan dibuat.

SARFlow report should be:

- draft administratif;
- berbasis timeline;
- berisi informasi terkonfirmasi, belum lengkap, dan konflik;
- tidak menjadi pernyataan publik resmi.
