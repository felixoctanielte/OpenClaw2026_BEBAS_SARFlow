# Service Flow

Alur administratif yang terlihat pada dokumen:

1. Pelapor datang langsung atau menghubungi Badan Nasional Pencarian dan Pertolongan melalui kanal resmi.
2. Pelapor melaporkan kejadian kecelakaan, bencana, dan/atau kondisi membahayakan manusia.
3. Petugas menerima dan mencatat laporan.
4. Petugas memverifikasi dan mencari informasi lebih lanjut tentang kejadian.
5. Petugas pencarian dan pertolongan bergerak menuju lokasi kejadian untuk melaksanakan operasi SAR.
6. Laporan hasil operasi disampaikan melalui mekanisme resmi.

SARFlow implication:

- Urutan agent harus mengikuti: receive -> record -> verify -> brief -> timeline -> draft report.
- SARFlow membantu administrasi awal; keputusan operasional tetap pada petugas/komando lapangan.
- Semua event komunikasi penting harus masuk timeline.
